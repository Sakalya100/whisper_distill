# docs

Research write-ups, decision records and published materials for the project.
Anything that came out of a research pass lands here, dated, with its sources attached.

| Path | What it is |
|---|---|
| [`01-kaggle-execution-plan.md`](01-kaggle-execution-plan.md) | The working plan: budget, workflow, gates, first moves. Living document. |
| [`research/`](research/) | Raw findings from each research pass, dated, with sources. Append-only. |
| [`decisions/`](decisions/) | Short decision records. One file per choice that would be expensive to revisit. |
| [`artifacts/`](artifacts/) | Source of published pages. |

## Conventions

- **Research notes are append-only.** A later pass gets a new dated file; it does not
  rewrite an earlier one. The plan is the only document that gets edited in place.
- **Every claim carries its source or its status.** Anything unverified says so inline,
  with the experiment that would settle it. See `[UNVERIFIED]` markers.
- **Decision records state what would reopen them.** A decision with no reopening
  condition is an assumption in disguise.
